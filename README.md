# Surya Sundar — Portfolio

Dark-themed developer portfolio. All content is driven from `src/data/portfolio.json`.

## Quick Start (Vite)
```bash
npm install
npm run dev      # localhost:5173
npm run build    # outputs to dist/
```

## Deploy
- **Netlify**: Drag & drop the `dist/` folder after `npm run build`
- **Vercel**: `vercel --prod` (auto-detects Vite)
- **Static**: Use `surya-portfolio.html` directly — no build needed

## Editing Content
All site content lives in `src/data/portfolio.json`.
Edit it and the entire site updates automatically.
